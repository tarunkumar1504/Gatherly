# Gatherly

A responsive event-planning dashboard for birthdays, weddings, community events, baby showers, and other celebrations. The app runs on Node.js without third-party runtime packages.

## Run locally

1. Install Node.js 20 or later.
2. In PowerShell, open this folder and run:

   ```powershell
   npm start
   ```

3. Open <http://127.0.0.1:3000>.

Your plans are stored in this browser's local storage. They are not accounts, encrypted records, backed-up data, or shared plans. Anyone using this browser profile—and scripts running on this site—can access that local data; avoid storing sensitive personal information and use a trusted device. The Share button copies or shares an event summary only; it does not publish your private budget, checklist, or timeline.

## Optional generative AI

Curated, event-aware suggestions work without credentials. To enable suggestions generated by OpenAI, set the key on the server before starting it:

```powershell
$env:OPENAI_API_KEY = "your-key"
$env:OPENAI_MODEL = "gpt-4o-mini" # optional
npm start
```

The browser never receives the API key. When someone asks for an AI idea, the server sends the event name, event type, date, location, guest count, and budget to OpenAI. Do not enter information you would not want sent to the configured AI provider. AI suggestions can be inaccurate; review them before acting. The server listens on `127.0.0.1` by default. Keep it on a trusted, local network; exposing it publicly needs authentication and production-grade hosting protections.

## Features

- Create and switch between up to 20 locally saved event plans.
- Start with event-specific timelines and checklists for weddings, birthdays, community events, baby showers, and other celebrations.
- Edit the date, venue, guest count, and overall budget; update vendor bookings and see their prices reflected in the budget.
- Track checklist progress, add tasks and timeline moments, and save ideas between visits to the browser.
- Generate optional AI ideas through a server-side proxy, or use clearly labeled curated suggestions without a provider key.
- Use the mobile navigation, native accessible dialogs, visible keyboard focus, screen-reader labels, and reduced-motion support.

## Tests

Run the dependency-free unit, HTTP security, and accessibility-contract tests:

```powershell
npm test
```

The tests use Node.js's built-in test runner. The server validates requests, caps request size and AI request rates, applies security headers, restricts browser cross-origin requests, and validates AI output before returning it.
